# FlowDM Implementation Plan

> **For agentic workers:** execute the scoped tasks below with TDD and independent review. User requested autonomous implementation and self-testing; do not pause for routine design choices.

**Goal:** Deliver a runnable Windows desktop downloader with portable Windows/Linux/macOS source and packaging.

**Architecture:** Dependency-free Node transfer engine behind isolated Electron IPC. Separate browser Native Messaging bridge and local-only UI.

**Tech Stack:** Electron 45, JavaScript CommonJS, node:test, c8, Playwright, electron-builder.

**Spec:** `docs/DESIGN.md`; reconstructed basis `../IDM/analysis/RECONSTRUCTION_SPEC.md`.

## Global Constraints

Preserve all original analysis artifacts. Own branding/source. No auto execution of downloaded content. No overwrite or combining different representations. Native Messaging uses 4-byte byte length, never JSONL. >=80% unit/integration coverage. Report native OS test gaps honestly. No push/publication or system-wide installation.

## Review Focus

- Corrupt partial writes, crash ordering and validators changing mid-transfer.
- Existing paths, reserved names, symlinks and malicious Content-Disposition.
- Cancellation during retry or HTTP response and double-start races.
- Renderer/bridge input and cross-origin credential leakage.
- Packaged startup, persistent resume and graceful OS shutdown.
